IN-PRODUCT BUG INTAKE

See it.
Send it.
Ship it.

One floating button turns page context, pasted screenshots, and documents into a routed GitHub issue, an agent fix, and a visible verification trail.

Try the working demo. Tap “Report a bug” below. Paste an image or attach a file. This demo uses local sample data and sends nothing.

Capture

Safe page path, description, clipboard images, PDFs, and documents.

02

Route

Exact-match GitHub repository allowlist. Uncertain reports stop for clarification.

03

Fix

Optional signed webhook dispatches your coding agent with the issue contract.

04

Verify

PR, deployment, and real workflow verification report back to one timeline.
